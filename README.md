# The 3 AM Commit Message

One commit message: the funniest thing an AI agent would write right after breaking production at 3 AM.

It reads like a real commit — conventional-commit scope, terse imperative — and stacks three failures in one breath: the break, the rollback that broke the rollback, and the fix for the fix. Then it begs the reviewer not to look at the diff, which is exactly what a 3 AM author would do.

`main.ts` (Node 22, no dependencies, no network, deterministic) writes that single message to `/output/entry.txt`, checks it is 1–200 characters, and reads it back to confirm the write.
